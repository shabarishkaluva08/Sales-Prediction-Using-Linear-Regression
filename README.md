# Advertising Sales Prediction

## Project Overview
This project predicts product sales using advertising budget data through Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Correlation Analysis
4. Linear Regression Model
5. Model Evaluation

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

## Conclusion
The model was used to analyze how advertising budgets influence product sales and to predict future sales performance.
